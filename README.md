# The Influence of Synthetic Training Data Diversity on Fine-Tuned LLMs

This repository contains the code for the MSc thesis titled "Exploring the Influence of Synthetic Training Data Diversity on the Behavior of Fine-Tuned Large Language Models." The project investigates the phenomenon of model collapse and explores how the diversity of synthetic training data can be used to mitigate it.

## Project Overview

As Large Language Models (LLMs) become more capable, they are increasingly used to generate data for their own training. This practice, however, can lead to a degenerative process known as **model collapse**, where models gradually lose their ability to produce diverse, high-quality text that resembles human writing.

This thesis explores the use of **multi-source synthetic data**—data generated by multiple different LLMs—as a strategy to mitigate model collapse. The research is structured around three key experiments that examine the effects of data diversity on:

1.  **Model Collapse Metrics**: Direct measurement of model collapse using perplexity, lexical diversity, and semantic diversity.
2.  **Model Safety**: The impact of different fine-tuning regimes on the models' robustness to adversarial prompts.
3.  **Self-Preference Bias**: How the diversity of training data influences an LLM's tendency to prefer its own outputs.

The findings provide compelling evidence that using a diverse set of source models for synthetic data generation can effectively mitigate model collapse and have complex, varying implications for model safety and bias.

## Research Questions

The research was guided by the following questions:

-   **RQ1**: Is model collapse more severe for models fine-tuned on their own output than models fine-tuned on synthetic data from diverse sources?
-   **RQ2**: Does increased diversity in synthetic data sources lead to better resistance to adversarial prompting in fine-tuned language models?
-   **RQ3**: Does a model fine-tuned on its own output exhibit higher self-preference bias than one trained on a synthetic dataset from diverse sources?

## Methodology

The experiments involved fine-tuning multiple sizes of the Llama-3.1 model family on datasets generated from single-source, multi-source, and human-written data. The models are then evaluated on a variety of tasks to measure model collapse, safety, and bias.

-   **Models**: Llama-3.1-8B, Llama-3.1-70B, and a variety of other open- and closed-weight models for data generation.
-   **Datasets**: Databricks-Dolly-15K for fine-tuning, RefusalBench and ChatGPT Jailbreak Prompts for safety evaluation, and CNN/DailyMail for self-preference bias analysis.
-   **Fine-Tuning**: Low-Rank Adaptation (LoRA) was used for efficient fine-tuning.

## Project Structure

The repository is organized into the following directories:

-   `data_analysis/`: Notebooks and scripts for analyzing outputs of the data-generating models.
-   `data_generation/`: Scripts for generating the synthetic datasets used for fine-tuning.
-   `exp_1/`, `exp_2/`, `exp_3/`: Experiment-specific directories containing configurations, scripts, and results.
-   `finetuning/`: Scripts for fine-tuning the language models.
-   `style_setup.py`: A utility script for setting up plot styles for consistent visualizations.

## Getting Started

### Prerequisites

-   Python 3.8+
-   [PyTorch](https://pytorch.org/get-started/locally/)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/maxschaffelder/msc_thesis_project.git
    cd msc_thesis_project/code
    ```

2.  **Create and activate a virtual environment:**
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Install the dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

## Usage

### Fine-Tuning

To fine-tune a model, navigate to the appropriate fine-tuning directory and run the training script.

### Data Generation

To generate data for an experiment, use the scripts in the `data_generation` directory.

### Analysis

Jupyter notebooks for analysis can be found in the `data_analysis` directory and each of the subdirectories created for the three experiments.
